# 🩺 Disease Prediction using Machine Learning

A machine learning project that predicts different diseases using patient health data and compares multiple classification algorithms.

### 🧠 Models Used

* Logistic Regression
* Support Vector Machine (SVM)
* Random Forest
* XGBoost

### 📊 Datasets

The project works with three disease datasets:

* ❤️ Heart Disease
* 🩸 Diabetes
* 🎗️ Breast Cancer

### ⚙️ Workflow

```text
Data → Preprocessing → Train/Test Split → Model Training → Evaluation → Comparison
```

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC

The project also includes confusion matrices and ROC curve comparisons.

### 🛠️ Tech Stack

**Python • Pandas • NumPy • Scikit-learn • XGBoost • Matplotlib • Seaborn • Jupyter Notebook**
